# Field-testing Cat Snap

## Before you head out
- Install the app to your home screen (see README).
- Open it once on Wi-Fi, allow location, and open the **Radar** so the map for your area is cached.
- In **Catdex → Settings**, set your username. Turn **Show demo cats** off if you want to see only real snaps.

## Checklist
| Area | Try this | Look for |
|---|---|---|
| Snap | Photograph a cat outdoors and post it | Photo orientation, how long saving takes, a sensible rarity |
| Location | Check the GPS badge on the Radar | Accuracy (±m) outdoors vs near buildings |
| Repeat cat | Open a cat you snapped before → **Saw them again** | Radar moves to the newer blurred spot, sighting count goes up |
| Offline | Turn on airplane mode, open the app, snap a cat | App opens, the snap saves, the cached map still shows |
| Edit / delete | Fix a typo, change the photo, delete a test snap | Changes stick after closing and reopening the app |
| Radar | Switch Map / Radar views, change range and time | Pins match the nearby list, nothing overlaps badly |
| Plus | Toggle Plus in Settings | Ads disappear, radar options unlock |
| Backup | **Save backup**, then **Restore backup** | All snaps and photos come back |

## Notes to capture while testing
Put these in a comment on a snap, or keep a notes file:
- Moments the app got in the way of photographing the cat
- Fields you skipped or wished existed
- Places GPS was poor
- Anything that felt unsafe for the cat (location detail, crowding)

## Known limits of the field-test build
- Data stays on one phone. There are no accounts and no shared feed yet. Back up regularly.
- Demo cats (including Claude) are placed around your first GPS fix. They aren't real sightings.
- iOS may clear data for web apps that aren't opened for several weeks. Installing to the home screen and backing up reduce the risk.
- Plus and the ads are mock-ups. No payment, and no real advertisers.
